# Developer Personal Portfolio

An elegant, modern, responsive personal portfolio website built with pure **HTML5**, **CSS3**, and **Vanilla JavaScript** for **ABDUL ASEES RASHIDA PARWIN**.

![Portfolio Preview](images/profile.jpg)

## 🌟 Key Features

- **Dark Glassmorphism Theme**: Sleek dark space styling with frosted backdrop blurs and glowing accents.
- **Interactive Particle Background**: Pure HTML5 Canvas floating node system reacting to mouse movements.
- **Hero Typing Effect**: Smooth auto-typing and deleting loop for job title switching.
- **Dynamic 3D Tilt Cards**: Perspective tilt tracking on hover for project cards.
- **Scroll Reveal Animations**: IntersectionObserver powered fade-in and slide-up transitions.
- **Animated Skill Progress Bars & Stat Counters**: Automatically trigger when scrolled into view.
- **Real-Time Contact Form Validation**: Client-side form checking with interactive error states and toast notifications.
- **Mobile First & Fully Responsive**: Responsive navbar drawer, flexible grids, and mobile-friendly touch targets.
- **Downloadable CV Asset**: Direct download link for `assets/cv.pdf`.

## 🚀 How to Run Locally

1. Clone or download this repository.
2. Open `portfolio/index.html` in any modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari).
3. Alternatively, launch a lightweight local server (e.g. VS Code Live Server or `npx serve`).
